## Local-testing model

FREEzzz Platform supports selecting a ROM from the user's local device.
That model is intentionally different from distributing copyrighted ROM files
through this repository.

If a rights holder later grants written redistribution permission, add the
permission record and exact license terms here before publishing the ROM.

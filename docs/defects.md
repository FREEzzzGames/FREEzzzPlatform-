# FREEzzzyPortal — Defect Log

Этот журнал содержит пользовательские дефекты, найденные при тестировании production-сборок.

| ID | Недочёт | Область | Приоритет | Статус | Найдено в |
|---|---|---|---|---|---|
| FZP-001 | Системные панели Android (status bar сверху и navigation/gesture bar снизу) перекрывают интерфейс приложения. Контент FREEzzzyPortal не учитывает безопасные отступы Window Insets: верхняя часть заголовка оказывается под status bar, нижняя панель интерфейса — под navigation bar. | Android UI / Window Insets | High | OPEN | 0.1.1 |

## FZP-001 — детали

**Наблюдение:** на Android системная строка состояния и нижняя gesture/navigation bar отображаются поверх интерфейса приложения.

**Ожидаемое поведение:** содержимое приложения должно полностью находиться в доступной области между системными панелями либо корректно использовать edge-to-edge с применением Window Insets, чтобы интерактивные элементы не перекрывались.

**Доказательство:** пользовательский скриншот тестирования Android 0.1.1.

**План исправления:** точечно исправить Android Window Insets/edge-to-edge для WebView-контейнера, проверить верхний и нижний безопасные отступы на текущем устройстве, добавить регрессионную проверку и выпустить следующую тестовую версию.
